
#SIH2K25  
Internal Hackathon 2K25 🏆  

Proud to present our project **“Smart Tourist Safety”** — a multi-role Tourist Monitoring and Emergency Response System designed to make travel safer through real-time monitoring, geo-fencing, emergency alerts, and coordinated response.

Our platform connects tourists, police authorities, tourism departments, and administrators through dedicated role-based dashboards.

## Key Features

### 👤 Tourist Module
🔸 Digital Tourist ID and profile management  
🔸 Personal safety score and safety status tracking  
🔸 One-tap emergency panic/SOS alert  
🔸 Current location tracking and geo-fencing  
🔸 Trip itinerary management  
🔸 Emergency contact details  
🔸 Real-time safety alerts and notifications  

### 👮 Police Department
🔸 Police Command Center for emergency response  
🔸 Real-time tourist location monitoring  
🔸 Active alerts and incident tracking  
🔸 Incident assignment and status management  
🔸 Critical alert monitoring  
🔸 Tourist statistics and response-time analytics  
🔸 Incident resolution and emergency coordination  

### 🏛️ Tourism Department
🔸 Tourism management dashboard  
🔸 Safety zone creation and management  
🔸 Risk-level and zone-capacity monitoring  
🔸 Tourist attraction information management  
🔸 Emergency procedures and tourist advisories  
🔸 Weather and safety notifications  
🔸 Tourism analytics and report generation  

### ⚙️ Admin Panel
🔸 System health monitoring  
🔸 User and role management  
🔸 System analytics dashboard  
🔸 Security and API configuration  
🔸 Backup and recovery management  
🔸 Emergency alert configuration  
🔸 Geo-fence violation alerts  
🔸 Daily reports and system notifications  

The platform also ensures **role-based access**, so every user can access only the dashboard and information relevant to their responsibility.
